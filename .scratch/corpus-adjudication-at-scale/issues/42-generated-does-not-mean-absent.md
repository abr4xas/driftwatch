# 42: `generated` does not mean absent

**What to decide:** what rule comes out of `generated-bundle`, ticket `37`'s fourth class.

**Type:** prototype

**Blocked by:** nothing.

**Status: resolved 2026-09-24.** Refused, and the class rests on an inference that is false
more often than not. No code changed.

## The class

36 findings in 31 repositories, 32 still live in 27. Four shapes in them, all of them the
author's own marker that a tool produced the file:

| shape | findings | repos |
|---|---|---|
| a `generated` path segment | 16 | 7 |
| a `*.generated.*` filename | 11 | 3 |
| a `*.gen.*` filename | 4 | 2 |
| a `_generated` path segment | 2 | 1 |

They look like the best-marked class yet: unlike `runtime-log`'s vocabulary, these are not
words that happen to describe the file, they are a convention the author adopted **on purpose**
to say "a tool wrote this".

## And that is exactly why the rule fails

`GENERATED` works because `dist/` and `node_modules/` are **not versioned**. The inference the
class rests on is that `generated` implies the same thing. Counted over the 2599 clones, by
repositories rather than by distinct segments:

| shape | versioned in | would quiet |
|---|---|---|
| `generated/` | **99** repos | 7 |
| `*.generated.*` | **75** | 3 |
| `*.gen.*` | **63** | 2 |
| `_generated/` | **16** | 1 |

**People commit generated code.** Prisma clients, protobuf stubs, GraphQL types, TanStack's
`routeTree.gen.ts`, Convex's `_generated/` — all of them regularly tracked, which is how they
end up in the index and how driftwatch resolves them today.

So a missing `src/generated/x.ts` is not noise. In 99 repositories of 2599 that directory is
versioned, and a document naming a file under it that is gone **is drift** — the generator was
removed, the output was deleted, the path moved. Silencing it would turn the best-signposted
kind of drift into the one this tool cannot see.

Every ratio runs 14:1, 25:1, 31:1 against. There is no narrowing: the marker is accurate about
what produced the file and says nothing at all about whether it is in the repository.

## What is actually behind the false positives

The corpus's own case is `northword/zotero-format-metadata` `AGENTS.md:44`:

> On startup it loads the bundled script `content/scripts/linter.js` (from `src/index.ts` via
> esbuild) into a sandbox

The path never occurs, and what makes it not-drift is **the sentence**: bundled, from
`src/index.ts`, via esbuild. `context-prose.ts` already holds `is generated` and `generated by`
and neither fires, because this author wrote "bundled … via esbuild".

That is where this class lives — in prose, not in path shape. Widening the hedge vocabulary is
possible and is not done here, for the reason ticket `27` measured: `HEDGED_SPLIT` already
carries more doubt than anything else in the system, `bundled` is an ordinary English word, and
`AGENTS.md` names `src/extract/` as where the risk concentrates. A vocabulary change there is
its own ticket with its own before-and-after, not a footnote to this one.
